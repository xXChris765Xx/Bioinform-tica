# Visor 3D interactivo con Three.js

Proyecto de la práctica 01.

## Archivos
- index.html
- style.css
- main.js

## Funciones
- Escena 3D
- Cámara en perspectiva
- Renderer
- Cubo, esfera y plano
- Materiales
- Iluminación
- OrbitControls
- Animación con requestAnimationFrame
- Carga de modelo .glb
- Raycasting para seleccionar objetos

## Ejecutar
Desde esta carpeta:

python -m http.server 5500

Después abrir:
http://localhost:5500

También puede publicarse mediante GitHub Pages.
